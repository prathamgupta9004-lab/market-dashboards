How to read this
Book-to-bill = orders won in the last 12 months ÷ revenue billed in the last 12 months (TTM). Above 1.0x the company is adding work faster than it executes it, so the order book should grow; below 1.0x it is eating into its backlog. Order book ÷ revenue is the years of revenue already in hand. Inflow counts only orders the company disclosed with a value in an exchange filing; companies do not file every order (only those they judge material), so a low figure can simply mean few filings. Sector bars add up the companies shown (after your market-cap filter).
How to read this
One row per company with at least one order-win filing that states a value. 12M inflow sums those values (L1 → LoA → contract filings for the same project are counted once). Δ 6M is the change in book-to-bill against six months earlier. Visibility = latest order book ÷ TTM revenue, in years. Filings shows filings with a readable value / all order filings in 12 months. Click a row for the monthly trend chart and every order behind it.
How to read this
The ten largest order wins of the chosen week, ranked by order size as a share of the company's trailing-12-month revenue (the figure that tells you how much one order moves the business). ⭐ marks orders of at least 5% of TTM revenue. Follow-up filings (an LoA after an L1 for the same value) and amended totals are left out.
How to read this
Every "Bagging/Receiving of orders" filing on NSE by the tracked companies since Mar-2023, read from the PDF. % TTM rev = order value ÷ revenue of the four quarters reported before the filing. % mcap uses the market cap on the filing date. Stage: L1 = lowest bidder (not yet awarded), LoI = letter of intent, LoA = letter of award/acceptance, Work order = purchase/work order or signed contract, Framework = rate contract / framework agreement (value is a ceiling). Annualised = value ÷ execution years, shown only when execution is longer than 12 months. Flags: first this FY first order filing of the financial year (Apr–Mar), largest this FY biggest valued order of that FY, follow-up same value filed again within 180 days, amended revised contract total. Values marked ≥ are a lower bound (company states a range or a size band); $ = converted from USD/EUR at ₹88/$ and ₹102/€ when no rupee value is given.
